# MVP and Delivery Roadmap

## Principle
The MVP is a production-capable first scope. It limits categories, geography, sources, and advanced features while preserving the final architecture’s identity, provenance, trust, security, localization, and API boundaries.

## Phase 0: Foundation
Deliver:
- Repository structure.
- CI/CD.
- environments.
- identity.
- PostgreSQL/PostGIS.
- taxonomy.
- canonical place schema.
- source registry.
- audit framework.
- observability baseline.
- Arabic/English localization foundation.
- security baseline.

## Phase 1: Core Discovery
Deliver:
- Initial cities/categories.
- approved data sources.
- ingestion and normalization.
- entity resolution.
- search index.
- keyword/category/geographic search.
- place profiles.
- distance.
- basic ranking.
- source attribution.
- correction reporting.

## Phase 2: Intelligence
Deliver:
- Trust engine v1.
- review intelligence.
- contextual ranking.
- recommendation engine.
- explanation engine.
- evaluation benchmarks.
- anomaly detection.

## Phase 3: Platform
Deliver:
- Community contributions.
- moderation.
- business claiming.
- business analytics.
- richer personalization.
- API products.
- partner integration.

## Phase 4: Expansion
Deliver:
- Additional Saudi cities.
- additional categories.
- MENA country modules.
- enterprise intelligence.
- advanced knowledge graph.
- more autonomous operations.

## Phase Gates
A phase exits only when:
- Acceptance criteria pass.
- Security review passes.
- Data quality is measured.
- Arabic/English journeys work.
- Operational dashboards exist.
- Recovery path exists.
- Documentation is current.
