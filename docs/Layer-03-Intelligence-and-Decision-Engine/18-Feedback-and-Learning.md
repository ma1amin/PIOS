# Feedback and Learning

## Feedback Sources
- Result click.
- Save.
- Navigation request.
- Contact action.
- Query reformulation.
- Explicit helpful/not-helpful feedback.
- Correction reports.
- Community validation.
- Comparison behavior.
- Search abandonment.

## Learning Principle
No single user action should create a major ranking shift. Behavioral signals are noisy and susceptible to manipulation.

## Evaluation
Offline evaluation should measure:
- Retrieval recall.
- Ranking relevance.
- Constraint satisfaction.
- Search success.
- Explanation faithfulness.
- Trust calibration.
- Duplicate accuracy.
- False-positive and false-negative moderation outcomes.

## Versioning
Every ranking, trust, recommendation, and major AI model release should have:
- Version identifier.
- Owner.
- Evaluation dataset/version.
- Evaluation result.
- Release date.
- Change summary.
- Rollback target.

## Experimentation
Online experiments require:
- Hypothesis.
- Primary metric.
- Guardrail metrics.
- Traffic allocation.
- Duration criteria.
- Statistical method.
- Stop conditions.
- Privacy review where necessary.

## Privacy
Analytics should minimize personal data. Use pseudonymous identifiers where practical, limit retention, and avoid collecting precise location history when aggregate context is enough.
