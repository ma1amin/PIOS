# SEO and Growth Architecture

## Search Intent
High-value organic intents include:
- Best dental clinics in Riyadh.
- Best bakeries in Jeddah.
- Best car workshops in a district.
- Electronics stores near a location.
- Category + service + city.
- Category + attribute + city.
- Place-name research.
- Place comparisons.

## Programmatic SEO
Generate indexable pages only when enough quality data exists to provide real user value. Avoid thin combinations of category/location pages.

Potential page types:
- Category by city.
- Category by district.
- Service by city.
- Place profile.
- Curated comparison where evidence supports it.

## Technical SEO
- Server-side rendering where useful.
- Stable clean URLs.
- Canonical tags.
- hreflang/localized routes.
- XML sitemaps.
- robots controls.
- structured data where accurate.
- fast page delivery.
- localized metadata.
- redirect handling for merged places.

## Trust and SEO
Do not publish invented ratings, synthetic reviews, or unsupported superlatives to increase search traffic.

## Growth Loop
Search discovery → useful decision → save/share/navigation → contribution/correction → improved data → better recommendations → stronger organic discovery.

## Measurement
Track:
- Organic landing quality.
- Search-to-action rate.
- indexed page quality.
- duplicate/thin page rate.
- query coverage.
- localized SEO performance.
- returning users.
- contribution conversion.
