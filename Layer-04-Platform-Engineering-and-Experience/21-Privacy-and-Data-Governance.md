# Privacy and Data Governance

## Principles
- Data minimization.
- Purpose limitation.
- Transparency.
- Access control.
- Retention discipline.
- User control.
- Secure processing.
- Provenance.
- Accountability.

## User Location
Precise location is sensitive operational data. Request it only for features such as near-me search. Use approximate location when sufficient. Do not retain continuous location history unless a defined product requirement, lawful basis, disclosure, and retention policy justify it.

## User Contributions
Separate public contribution content from private account data. Public attribution should follow the user’s configured identity model and privacy design.

## User Rights
Design workflows for applicable rights such as:
- Access.
- Correction.
- Deletion.
- Export.
- Consent/preference changes.
- Account closure.

## Data Classification
Suggested classes:
- Public.
- Internal.
- Confidential.
- Restricted.

Credentials, security secrets, sensitive identity data, and precise location histories should receive the highest appropriate protection.

## Governance Roles
Assign:
- Data owner.
- Data steward.
- Technical custodian.
- Security owner.
- Retention owner.

## Regulatory Mapping
For Saudi operations, perform a formal legal and technical mapping against applicable Saudi Personal Data Protection Law requirements and relevant cybersecurity obligations, including NCA controls where they apply to the organization or service context. Exact compliance obligations depend on the legal entity, processing activities, data categories, hosting/transfer model, and contractual relationships, so production compliance must be confirmed against the actual operating model.

## Retention
Retention is field-specific. Raw source payloads, audit logs, user telemetry, account data, and derived insights may require different periods. Define purpose, retention period, deletion method, and legal hold handling for each class.

## Cross-Border Processing
Before expanding providers or regions, document data location, processor/subprocessor relationships, transfer mechanism, contractual controls, and regulatory requirements.
